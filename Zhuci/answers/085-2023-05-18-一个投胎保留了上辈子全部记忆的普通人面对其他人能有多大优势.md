# 一个投胎保留了上辈子全部记忆的普通人面对其他人能有多大优势？

没有任何优势，甚至于这是一种酷刑。

/

二零二三年五月，你出生在了一个普通家庭里，由于某种不切实际的因素，在这个世界上确实存在着民俗当中的地狱。

你走过了阎罗殿，并侥幸没喝下那碗孟婆汤，你怀揣着这种兴奋跨过了奈何桥，并且投胎到了一户普通人家，成了一个大胖小子。

一切好像都和上辈子没有区别，除了你的根儿变小了一点。好吧，这影响不大，在你的心里这辈子必然是要成为人中龙凤的。

然后没过多久，你就迎来了人生当中的第一个巴掌。

当你睁着眼睛好奇地打量着周围一切时，你那新的父亲正心急火燎地瞪着你，因为你完全不哭啊，甚至于没有发出任何声音。

于是在担心你是否被羊水呛到的基础上，你的父亲狠狠甩了一巴掌，就打在你屁股上。

这下你真的哭了。

因为那完全是一种剧痛。

/

回到家里没多久，你迎来了你人生当中最痛苦的一段时间，那就是喝奶。

由于你完全保留了上一世的所有记忆，这就导致你和你新的父母完全没有血缘上的共鸣，你不得不接受一个现实。

那就是作为一个记忆正常的大龄男性，你正在做一件心理上很别扭的事。

而这种别扭你甚至无法拒绝。

于是在你那小小的脑子里，你纷乱的思维正在和你完全稚嫩的身体起最决绝的冲突。

性，恐惧，心理，崩溃，无数次在你的思维里反复。

你还有太多想做的事，可你没办法，你只能在夜深人静的时候安慰自己，没关系的，就当是坐牢。

然而这牢，你坐了很久很久。

/

值得庆幸的是，你终究没有死在思维焦虑里，而是挺过了那段时间。

现在的你开始上学了，并凭借着惊人的表现，让全家人都觉得应该给你报一个最好的小学。

你听到时有点压抑，因为那意味着这个普通的家庭要多出很大一笔支出，你想要试图说服父母，让他们相信你并不需要去那种地方。

然后这不可能，你的父母只是揉着你的头跟你讲，你还是个小孩子，还不懂，爸妈再苦再穷也不能耽误你。

于是没有任何决策权的你，只能够眼睁睁看着这个普通的家庭，进一步向贫寒前进。

你想着没关系，凭借着前世的记忆，小学对你而言依旧不成问题。

事实也的确如此，在最好的小学里你依旧表现惊人，不仅如此你还表现出了远超年龄段的成熟。

你觉得一切都会如此，人生正在像你设想的那样发展。

/

命运的打击很快便来临了，甚至没有留给你多少时间。

等你开始以万众瞩目的姿态进入初中时，你忽然便发现你无法掌控一切了。

你努力用脑子回想，却发现上一辈子的你，根本早就遗忘了初高中的知识。你本可以在小学的时候刻苦预习，但如果有这样坚韧的求学意志，很难想象你上一辈子怎么会是普通的男人。

你安慰自己没关系，即便如此，哪怕再来一遍也是比其他人有优势的。

然而你接着便发现，学业对于天赋的要求已然开始出现。

你依旧学不明白那枯燥无比的英语，你唯一的优势就是语文和数学确实比上辈子有了点进步。

这样的成绩让你保持在了年级前列，但已经不属于顶尖。

身边的人开始有些失望，而这种失望则在高中达到巅峰。

对你而言也是如此。

在高中的封闭与压力下，你完全无法想象，自己为什么要再经历一次这样的三年。你试图拼命地学习以维持成绩，但天赋已然决定了对于某些学科你毫无办法。

更令人痛苦的是，你已经完全没有任何熟悉的优势，因为你早就把高中知识忘完了，你本想在初中的时候开始预习，然而初中光维持现有成绩就够你力不从心了。

所以，你骤然间便回到了同一起跑线。

这样的落差和痛苦，反倒更让你难以进入状态，对你而言唯一的幸运，大概就是高中时追到了你喜欢的那个女孩，即便和她在一起的时候，总让你觉得有点罪恶感。

她太年轻，也太稚嫩。

痛苦之余，你也赫然发现原来的计划简直一塌糊涂，光应付学业你就花了绝大部分的时间，家里也没有多余的金钱去供你提前进行什么谋划。

而且你只是一个普通人，在金融方面上辈子你当了二十年的韭菜，做生意也没有成功过，你也不了解，不知道还有哪些渠道可供你实现阶级跃迁。

你认命了。

/

比上一世录取的大学更好一些，这或许是你的优势，但落差感依旧围绕在你和你的家庭当中。

你觉得有些丢脸，但好在大学离家里很远，这样那伤仲永的议论也不必传到你耳朵里。

拿着家里的生活费，你在大学里依旧保持着和女友的交往，似乎这是你唯一的天赋了，以足够成熟的心态来对待恋爱。

大学里你省吃俭用，努力存着钱，不停地回忆着上辈子走过的路。

你进过很多家公司，来来回回工作，除此之外你好像真的没有什么额外的收入。那么尝试去理财吧，也许从现在开始积累经验，对你将来会有帮助，你如此想着。

可是你省吃俭用下来的钱，还要负责你和女友的某种活动，但你依旧选择把它投了进去。

某一天你陪着女友回老家时，你坐在面包车上打着瞌睡，却忽然发现女友的老家和你上辈子的故乡是同一个地方。

你隔着窗户看到了上一世父母那破败的坟，但你只是偏过头，没人知道你在想什么。

/

时间还在飞速推移，你很快就毕业了。

浩大的就业市场里，你陷入了迷茫，和其他人的迷茫一模一样，你不知道该做什么，因为此刻的你真的太普通了。

你的学历平平，履历一般，但好在你在情感上拥有着真挚，这让你得到了你所认为的爱。

可是你真的不甘心。

于是你在顷刻间想到了答案，你决定去考基层公务员。

凭借着你上一世的人际交道，你坚信你起码在人情世故的处理上，会远胜过同样的年轻人。

这一次你似乎赌对了。

你真的考上了，并且凭借着小心翼翼地做人，和忠犬般的听话，以及游刃有余的事情处理态度，你得到了很多人的赏识。

你觉得也许真正的机会就在这里。

/

时间依旧没有停止转动，麻烦的事情接踵而至，由于你和女友分隔两地，双方家庭的矛盾愈发猛烈。

你需要房子，需要房子，需要金钱来照顾你那因操劳而身体逐渐开始步入腐朽的父母。

巨大的压力落在了你的肩膀上，偶尔梦醒时你会觉得一种不甘心油然升起，但痛苦依旧留存在你身上。

你开始变沉默了，因为太多东西无法和别人诉说。

你继续干着你的工作，却猛然意识到，也许提干真的是遥遥无期。

但你依旧很幸运，因为我赋予了你这样的幸运，你和你的初恋走到了婚姻的殿堂，而这其实是你人生里最不普通的一件事了。

只不过结婚的那一天你吐了。

大概是宣誓的时候，你忽然就想到了上一世。

在很多很多年前，你也做过这样的事，在宾客们面前握着一个女人的手，然后笑着对她说，我会爱你直到永远。

你忽然不知道永远到底是多久。

你也忽然不知道在你的心里，爱到底是什么。

/

时间的指针还在拨动，一切来的是如此的快。

妻子的怀孕，孩子的出生，父母的衰老以及死亡。你开始在工作之余来回地穿梭于医院，以及政务大厅。

你机械般地做着上一辈子你都做过的事，唯一的波动大概就是孩子出生那天。

你发了疯似的冲进产房，要把刚刚出生的孩子摔死。

你被许多人按在地上，可你却只是大吼着，他和我一样。

你知道，你或许只是过于敏感了，但很多人都开始觉得你疯了。

接着便是你的衰老，和妻子的衰老，你花了一辈子时间却也没有走到所谓官的位置，但你依旧和妻子凑出来了孩子的教育与生活费用。

你支撑着这个家，操心着孩子的一切，然后慢慢的。

孩子长大了，你老了。

再然后。

你的父母，岳父岳母都死了，你的妻子也死了，这一世你认识的朋友，长辈，也开始慢慢离世。

妻子死的那一天，她握着你的手，她仿佛回到了最开始认识你的时候，眼睛里闪着好奇的光，就像十六岁那年。

她轻轻地跟你说，其实她觉得一辈子都没有看透你，她觉得你好累好累。

但她又笑着跟你说，但跟你相爱的这辈子，她觉得足够了。

你就这样握着她的手，看着她眼里的光骤然熄灭。

可那一刻你没有哭，你只是陷入了呆滞。

你想到了很多很多年前，你也这样握着过另外一个女人的手，而她早就死了。

/

妻子死后，你叫来了儿子，他此刻已然成家立业，看起来疲惫极了。

你审视着这个儿子，你似乎也从未看透他，曾经你有你的防备，但此刻你却忽然释然了。

你用力地拥抱了他，然后告诉他你要离开这里，让他不要来找你。

你的儿子有些惊讶，但他终究点了点头。

离开家后，你去了很多地方。

去了上一辈子你记忆当中的某座山上，在一片杂草里，有着两座坟，一座是你，另一座是你那个时候的妻子。

你忽然栽倒在了坟前，然后便昏睡了过去。

梦里你看见了很多人，大家都在等着你，你想哭，可刚发出声音，便又从昏沉中醒过来。

你艰难地站起来，并坐着面包车，去了一座很远的庙。

你记得，上一世你年老的时候，庙里曾经有一个小和尚。而等你再次踏进这座庙时，却只有一个老和尚了。

/

老和尚并不对你的到来感到惊讶，他只是把你领到菩萨面前，问你是否对一切感到遗憾。

你抬起头看着那庄严肃穆的菩萨像，似笑非笑地对老和尚说，曾经你竭尽全力想去实现阶级跃迁，成为不普通的人。

曾经你以为你最大的失败，是依旧成为了普通的人。

但现在你似乎明了了，你真正感到遗憾的，是你从来没有珍惜过普通人的一生。

你告诉老和尚，你浪费了好多好多的时间，也浪费了好多好多的爱。你有很多问题到最后没有想明白，比如你到底是谁，比如你到底爱谁，又如此一切到底从何而起，从何而结。

老和尚也笑了笑，他对你说，人生没有重来。

你摇了摇头，你说，人生不要重来。

老和尚指了指院里的那口大钟，对你说，他在这里敲了一辈子的钟，每次他想不明白该怎么样成佛的时候，他就会这样去做。

老和尚劝你也去敲一敲，你去了。

你用力抓着绳子，然后使劲敲了过去，一声清脆的钟声猛地在四周响起，直至响彻云霄如同鹤鸣。

这声音穿过寺庙的围墙，穿过山上的蔓草，穿过小河上残破的桥，穿过那一望无际却又荒凉的原野。

这钟声席卷着山风，裹挟你的爱恨，你的迷茫，你的对错，就这样穿过你两世的生命，最后打着转儿，落在了你的坟上。

你忽然悟到了什么，这也许是你这普通人最后的一点禅机，在生命的尽头。

老和尚走到你身边，他看着你的气息越来越平静，越来越轻微。

你看着老和尚，你告诉他，你想到了他一直困惑的那个问题，人到底该如何成佛。

老和尚俯下身子。

你用尽最后的力气说出了那三个字。

莫回头。

终于，你真的死去了。
